Three shortcuts. No setup.

They work from any app and need no Accessibility permission. The full list is one click away in the menu bar.

⌃⌥A

Capture an area

Drag to select, then move or resize. Annotate, then copy, save, pin to the screen or copy the text inside it.

⌃⌥Z

Zoom the screen

Freeze and magnify. The mouse pans, the wheel zooms, a click pins the view so you can draw.

⌃⌥D

Draw on the screen

Pen, highlighter and shapes in six colors, plus whiteboard and blackboard modes.

Made for explaining things

Every tool is there because someone needs to show what they mean on a real screen.

Annotate before you share

Pen, line, arrow, rectangle, highlighter, text and numbered steps on any capture.

Hide what is private

Blur passwords, names and numbers before the screenshot leaves your clipboard.

Copy text from images

On-device text recognition turns any selected area into text you can paste.

Pin a screenshot

Keep a capture floating above your windows while you work from it.

Pen pressure on tablets

Stroke width follows how hard you press with a tablet pen.

Nothing leaves your Mac

Screenshots can contain passwords, tickets and customer data. ZoomDNZ was built so they never have to go anywhere. This page loads no fonts, scripts or trackers either.

  • No network code. The running app holds no network connection.
  • No account, no cloud, no telemetry, no third-party libraries.
  • Screenshots save to a private folder in Documents that only you can read.
  • Hardened runtime on, and the source is open for anyone to audit.

Build it in two minutes

There is no installer yet. You compile it once with Apple’s free command line tools and drag the app to Applications.

  1. Get the tools and the code

    xcode-select --install
git clone https://github.com/1kenz/ZoomDNZ.git
cd ZoomDNZ

  2. Build and open

    ./build.sh
open build/ZoomDNZ.app

    The build creates one universal app that runs on both Apple Silicon and Intel Macs.

  3. Allow screen recording

    Open System Settings › Privacy & Security › Screen Recording, switch ZoomDNZ on, then reopen the app. macOS asks once because the app can only see your screen with this permission.
